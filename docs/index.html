Quick start

From install to evidence in minutes.

This is an unreleased local development preview. The structured APIs shown here are not yet available from the published PyPI package. For this preview, install the development checkout with pip install -e '.[selenium]'. Capture a tightly cropped element image, then choose the simple or structured API.

01

Install

Add the adapter extra for the automation framework you use.

pip install pyxelator[selenium]

Also available: playwright, appium, or dev.

Crop a distinctive element from a screenshot. Keep the crop tight and avoid surrounding layout.

Act

Pass your driver, template, and confidence. Check result.ok before continuing.

from pyxelator import click_result

result = click_result(
    driver, "save.png",
    confidence=0.8
)
assert result.ok, result.reason
Keeping existing tests? The classic find(), locate(), click(), and fill() helpers keep their established bool/tuple/None returns. Adopt structured results only where you need evidence.

Structured v1 API

Three calls, one explicit contract.

Match results preserve confidence, bounds, scale, ranked candidates, and refusal reasons. Action results add what happened after the match.

◎

match_result()

Inspect screenshot bytes without acting.

match_result(
  screenshot_bytes,
  template_path,
  confidence=0.7,
  grayscale=True,
  scales=None,
  ambiguity_margin=0.02,
) → MatchResult
  • Ranks spatially distinct candidates
  • Reports score, rectangle, scale, and margin
  • Truthful only when ok is true
↗

click_result()

Validate once, then click safely.

click_result(
  driver, image,
  confidence=0.7, *,
  ambiguity_margin=0.02,
  verify_image=None,
  verification_confidence=None,
  verification_expected_visible=True,
  debug=False,
) → ActionResult

One pre-action screenshot. No click occurs unless the match is both confident and unambiguous.

The accepted coordinates go directly to the framework adapter, avoiding a second match against a changed screen.

Safety behavior

Uncertain pixels produce zero actions.

Structured actions fail closed. A refusal still returns useful evidence so you can improve the template or choose a safer fallback.

1

Capture

Take one fresh screenshot from the driver.

→
2

Validate

Require confidence and a clear winner.

→
3A

Act

Click or fill only when match.ok is true.

3B

Refuse

Return a reason. Do not touch the UI.

≠ Ambiguity rejection

If another passing candidate falls within the default 0.02 score margin, the target is marked ambiguous_match. No action occurs.

↓ Threshold gate

A best candidate below confidence returns below_threshold with its score and bounds for diagnostics.

◇ Invalid input handling

Unreadable screenshots, invalid or flat templates, unusable scales, and matcher errors become explicit results—not accidental actions.

✓ Optional verification

Match a fresh screenshot after the action. You can require an image to appear or prove disappearance with a valid below-threshold result.

!
Check ok, not only found.

found means the winner passed the score threshold. ok also means the winner was not made unsafe by a similarly scored, spatially distinct candidate.
